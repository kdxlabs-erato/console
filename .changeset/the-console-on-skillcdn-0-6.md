The console on SkillCDN 0.6: every `@skillcdn` package is taken at 0.6.1, and this is the console's 0.6.0 (ADR-0034). What a 0.6 deployment says more of a pack is passed on as every answer of a pack is, and printed by the command: a page of a skill ends between two blocks of Markdown where it can, outside a table and a fenced code block, and says how many pages follow it (`pagesLeft`); a page that goes on with a long table carries the table's first two lines (`tableHead`); the first part of `console skill` names what it shortened, and the files of other packs the skill links to by a skill URI, which are not read through the console (`packReferences`); and `console skills` says the page a pack's manifest names as the first to read, `Start here, before a task: console skill --file <path>` (`start`). A pack the console reads from a directory is read under the reading rules of 0.6, so a manifest there may name its `start` and a skill may link another pack's file.

The console's own pack names its first page, `docs/start.md`: which skill a request leads to, the two ways the pack is read, and the specifications the skills stand on. The package carries it with the other documents.
