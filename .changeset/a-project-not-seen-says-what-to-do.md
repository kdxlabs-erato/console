A project the console does not have, or does not show you, is said in full by every command that works in the project a directory's file or `CONSOLE_PROJECT` names, where `console rules`, `console tasks`, `console take` and the rest printed the console's bare `project.not_found`: the key, the console, what named the key, and the two things to do about it. Where the project is there and you are not in it, one of its owners lists you (`console member add <login> --project <key>`); where the key is wrong, the directory is bound anew (`console use <key>`), or the variable set to another. `console whoami` ends on the same two lines, in place of the hint to bind the directory to another project. A key typed with `--project` is refused in the console's own words, as before.
