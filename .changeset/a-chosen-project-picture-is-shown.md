A picture chosen for a project's mark is shown on the mark before the form is sent. The pages' policy lets an image come from the console or from a `data:` address alone, and the form showed the chosen file by a `blob:` address, which the browser refused, so the mark kept its symbol until the project was saved; the file is now read into a `data:` address, where it is no larger than an icon may be.
