The package ships the shell of a desk's dashboard, `template/desk-web`: the four files of a console of one's own that opens on the desk's page, built with `npm run build` and served by `console serve dist`. Two words in it are filled by the command that writes a desk: `__VERSION__` in `package.json` and `__TITLE__` in `index.html` and the README.
