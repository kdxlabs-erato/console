`console whoami` asks the console for the project the directory names, where it repeated the key it read: the line says the project's name beside its key and what named it, `.skillcdn-console.json` with the directory that holds it, `CONSOLE_PROJECT` or `--project` (`; project web (The web app), named by .skillcdn-console.json in /work/app`). A project the console does not have, or does not show you, now ends the command with exit `1` and `project.not_found`, after the lines that say who and where: a script or an agreement that checks a checkout's binding with `whoami` no longer passes on a key alone. `--json` gains `projectName` and `projectSource`; `project` is the key, as before. A directory that names no project is as it was (ADR-0112).
