The console's own rules, which hold on every board whose organization wrote none, say four things more and two things less. A task written from chat is written `--state ready`, so that it can be taken as written; in a project several repositories share, a task names its repository and is worked in a checkout of that one; work found on the way that the task does not cover is a task of its own, named in the report; and where no project is named, `console skills` reads the organization's pack. What the skill working-the-board and the command's help say already is no longer repeated there: what `console task <number>` prints, and how a host with a connection of its own names a skill.
