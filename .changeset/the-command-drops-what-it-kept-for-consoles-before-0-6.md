The command drops what it kept for consoles before 0.6. Since 0.6.0 it refuses a console older than that itself, so these paths no longer ran: the workspace's rules read whole where a console said no parts, with the refusal of `console rules write --workspace` there and the read of the rules that came before every such write (the write is now one request); a plugin's events narrowed by `--kind` in the command where a console did not; and the words for a console without the route of an account's own wake, without the organization's pack, and without what an account's first sign-in is held to. Nothing changes against a console the command takes.

What the pages read of an older console stays as it is: `console serve` carries their requests to a console the command does not judge.
