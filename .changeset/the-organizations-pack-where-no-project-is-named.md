`console skills` and `console skill` read the organization's pack in a directory that names no project, where they answered that a project had to be said: an agent in a desk, or in a folder a repository is about to be made in, finds and loads the organization's skills with no `--project`. The answer begins with a line that says whose pack it is; `--rows`, `--code` and `--json` carry none. The console serves it at `/api/v1/workspace/skills` and, under it, the reads a project's pack has, for every member of the workspace, with the workspace's SkillCDN token where the pack is private (ADR-0113); a console older than this answers that it does not, and the command says to name a project. The client gains `organizationPack()`, which answers a `PackClient`, the seven reads a `ProjectClient` and a `PluginClient` have.
